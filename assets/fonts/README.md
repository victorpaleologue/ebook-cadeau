# Bundled fonts

All fonts here are licensed under the **SIL Open Font License 1.1** and were downloaded
unmodified from <https://github.com/google/fonts> (see `SHA256SUMS`).

| File | Family | Use in eBook Cadeau | Licence file |
|---|---|---|---|
| `AtkinsonHyperlegible-*.ttf` | Atkinson Hyperlegible (Braille Institute) | body text, instructions, codes — chosen for unambiguous letterforms (0/O, 1/l/I) | `OFL-AtkinsonHyperlegible.txt` |
| `Spectral-*.ttf` | Spectral (Production Type) | default serif for synthesised spines and typographic covers | `OFL-Spectral.txt` |
| `BebasNeue-Regular.ttf` | Bebas Neue (Dharma Type) | default condensed display face for narrow spines | `OFL-BebasNeue.txt` |
| `CourierPrime-Bold.ttf` | Courier Prime | monospaced redemption code | `OFL-CourierPrime.txt` |

The OFL allows bundling, embedding in documents and commercial use; the fonts may not be
sold on their own and Reserved Font Names must not be used for modified versions.
