# Fact-check report — ISBN databases

_Produced by an adversarial fact-checker on 2026-11-12 for `docs/research/01-isbn-databases.md`. The corrections below WERE applied to that document in the same pass (status line: "fact-checked")._

## 0. Method and limits

- **Web search worked for this document.** 27 fresh WebSearch queries ran (10 in "extended" mode for prices and 2025–2026 changes). Queries were written from the claim, not from the document's wording.
- **WebFetch of vendor sites stays blocked.** I never opened a vendor page myself: what I have is the search tool's summary of each result page plus its URL. Where a verdict rests on such a summary I say "per search summary". Quotes are the summary's quotes.
- **Primary files re-read today on `raw.githubusercontent.com`** (HTTP 200): Open Library `nginx.conf`, `web_nginx.conf`, `processors.py`; the Google Books discovery document (rev. 20240214); python-stdnum `isbn.dat` (range file dated 2026-01-04); Libris `index.en.md`.
- **Not checked at all**: every French trade source (Dilicom, Electre, Decitre ORB, Tite-Live), every e-distributor contract, VLB and the other national trade bases, Hardcover, HathiTrust, Europeana, Trove, NDL, the legal authorities of §5, CORS headers of every service other than Open Library. No endpoint was called live. Those claims keep the markers the document already had.
- Verdict words: CONFIRMED (a fresh independent source agrees), PARTLY (true with a correction that matters), WRONG, OUTDATED, UNSUPPORTED (no evidence found; not the same as false).

## 2. Omissions and 2025–2026 changes

1. **`bib.fuzzyIsbn`** at BnF (row 2).
2. **Google Books API additional terms** forbid charging users without Google's written permission (row 10). The draft classed Google Books as merely "display-only".
3. **BnF does not catalogue most eBooks** (row 5): the hit-rate test of §6.4 should expect near-zero for eBook ISBNs at BnF.
4. **Crossref list-request limits** (row 18): a `filter=isbn:` call is limited to 1 request/s and one concurrent request without `mailto`.
5. **DNB blurb links**: DNB paused "blurb" hyperlinks in SRU/OAI data in July 2026 and reintroduced them with a new structure on 25 August 2026; old-style links stop answering on 25 February 2027. We do not store descriptive text, so no effect, but a parser must not treat those URLs as stable (https://www.dnb.de/EN/Professionell/Metadatendienste/Kataloganreicherung/Inhaltstexte/inhaltstexte.html).
6. **Amazon PA-API is gone since 15 May 2026** (row 21): Open Library's on-demand Amazon import path changed accordingly; irrelevant to us because `/isbn/` lookups do not import.

- The live behaviour of any endpoint, any CORS header in a real response.
- Licence version named by BnF and ABES; K10plus, Inventaire, BNE, Wikidata licence statements (Wikidata CC0 is common knowledge but was not searched).
- Google's caching clause and the exact branding text; whether keyless calls are served.

## Code that should change if this correction stands

- `crates/ebc-catalog/src/providers/googlebooks.rs` — the provider notes say "display only"; add that the Books API terms forbid charging users without Google's written permission, and gate the provider on an explicit configuration flag (for example `google_books_permission_ref`) in addition to the key. `crates/ebc-server`: do not enable Google Books in a paid flow by key alone.
- `crates/ebc-catalog/src/providers/sru.rs` (BnF) — consider `bib.fuzzyIsbn all "{isbn13}"` as the query, or as a second attempt after the exact `bib.isbn` pair; add a request-builder test. The licence note "read in a 2016 BnF page" can cite the current BnF conditions pages; keep `etalab-2.0` flagged as "version unverified".
- `crates/ebc-catalog/src/providers/sru.rs` (LoC) — `https://lx2.loc.gov/sru/lcdb` is reported not to complete TLS; keep the provider off and say so in its notes, or drop it.
- `crates/ebc-catalog/src/providers/sru.rs` (DNB) — the "CC0 from memory" note can be upgraded to "DNB press release 2015"; K10plus stays "from memory".
- `crates/ebc-catalog/src/providers/libris.rs` — the licence note should say CC0 is stated for the Swedish national bibliography and authority records only; the cache layer should not assume CC0 for non-Swedish records returned by Libris (treat as class A "licence stated for part of the data").
- `crates/ebc-catalog/src/providers/lobid.rs`, `finna.rs` — "CC0 is from memory" can become "confirmed"; CORS stays unverified.
- `crates/ebc-catalog/src/providers/crossref.rs` — notes: list requests are limited to 1 request/s, concurrency 1 (public) and 3 requests/s, concurrency 3 (polite); `min_interval_ms: 1000` is already compliant; make sure the driver never runs two Crossref requests in parallel without `mailto`.
- `crates/ebc-catalog/src/providers/wikidata.rs` — drop "5 parallel queries per IP" from any comment; keep the 60 s timeout.
- `crates/ebc-catalog` fixtures/tests — expect misses for eBook ISBNs at BnF; make the print-ISBN fallback a first-class path in `driver.rs` tests.
- Any ISBNdb configuration text or business-model input (`tools/` business model, `docs/research/12-…`) that uses USD 15 / 30 / 75: use 14.99 / 35.99 / 99.99 with daily caps 5,000 / 15,000 / 50,000.
- `crates/ebc-catalog` ONIX reader (when written) — accept List 158 codes 56 and 57 only from feeds declaring code lists Issue 70 / 71 or later; no behaviour change otherwise.
